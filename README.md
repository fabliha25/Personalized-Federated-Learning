# Pesronalized-Federated-Learning
This work represents a personalized federated learning (PFL) framework for cross-environment WiFi gesture recognition using Body coordinate velocity profile (BVP) induced from raw Channel State Information (CSI). It employs a two-phase training strategy: an initial phase where existing clients establish a Federated network, followed by a joint continuation phase where new clients are progressively integrated. To handle heterogeneous data distributions arising from varying gesture subset coverage across sessions and uneven user participation, the framework introduces severity-aware personalization: clients with reliable local class distributions receive personalized layers combining a shared backbone, while clients with sparse or skewed distributions rely solely on the shared backbone via FedProx proximal regularization. To prevent catastrophic forgetting of new clients joining, Elastic Weight Consolidation (EWC) is applied using a federated approximation of Fisher Information, where initial client locally computes and share only local parameter importance estimates rather than raw data. Experiments on the Widar3.0 dataset across 17 users, 3 room environments, and 12 gesture classes demonstrate a mean per-client weighted F1-score of around 84.60% averaged across two independent seeds (42, 100) and three heterogeneity scenarios/cases of initial and dynamic client settings, where dynamically joining clients consistently perform within 6% of the initially established clients regardless of which group leads, validating the framework's effectiveness for privacy-conscious robust gesture recognition.
