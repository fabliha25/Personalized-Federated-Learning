# Personalized-Federated-Learning
This paper presents an adaptive federated learning (AFL) framework for WiFi-based gesture recognition employing a two-phase training strategy: an initial phase in which existing clients collaboratively establish a federation, followed by a joint phase where new clients are progressively integrated while existing clients continue training. To handle heterogeneous distributions arising from uneven user participation and varying gesture subset coverage across sessions, the framework introduces severity-aware personalization: clients with reliable local class distributions receive dual-head architectures combining a shared backbone with personalized layers, while clients with skewed distributions rely solely on the shared backbone, with local updates constrained toward the global model via FedProx proximal regularization. To prevent catastrophic forgetting when new clients join, elastic weight consolidation (EWC) is applied using federated approximation of Fisher Information, where each client computes and shares only local parameters rather than raw data. Experiments on the Widar3.0 dataset across 17 users, 3 room environments, and 12 gesture classes demonstrate a mean per-client weighted F1-score of 84.80+-0.2% averaged across five independent seeds and three heterogeneity scenarios, with the F1 gap between established and incoming client groups ranging from 1.4% to 8.9% regardless of which group leads, validating the framework's effectiveness for environmentally robust gesture recognition.
